# Baseline parity matrix

Current owner decision: the Go beta is retired, and matching it is not an acceptance criterion.
This inventory is historical design provenance; frozen fixtures remain regression inputs and
safe preservation/replacement of beta installations is still required. Current wiring is in integration.md.

Baseline commit: `38c840b4a201bd348d898cd2d6d02fdd67a51c2b`. Anchors below refer to this immutable
commit, not to future Electron line numbers. This inventory describes existing behavior and its
required disposition; it is not evidence that a port passed. `KEEP` is implicit unless a row says
`REPLACE`, `EXTEND` or `DROP`. Target paths are under `src/` unless stated otherwise.

Verification abbreviations: **U** = unit/fault injection with temporary files; **D** = differential
against frozen Go baseline fixtures with controlled clocks, mtime and Git; **E** = Electron main/
preload/renderer E2E with fake native effects and temporary userData/profile; **W** = packaged smoke
in a disposable Windows user/VM. Mocked tests never count as native visual sign-off.
See [architecture](architecture.md), [IPC types](ipc-contract.md), [exclusive packages](work-packages.md).

The actual scaffold at `a737966` was also inspected with `git ls-tree`/`git show` (reference
only; no scaffold source changed in this document-only branch). Preserve its
`src/main/modules/<name>/` layout, data-dir.ts/ipc.ts/window.ts entry helpers, shared validators,
electron-vite and electron-tests/Playwright tooling. Its temporary settings-only behavior is
superseded by the version1 baseline contract. Provisional app:getInfo/settings:update/private
app:openExternal become app:get-info/settings:set/shell:open-external; retain settings:changed
and add the ledger/update/activation events specified in the IPC contract. AGENT_OPS_DATA_DIR
and .dev-data remain the actual scaffold override/development default; they are not config keys.
